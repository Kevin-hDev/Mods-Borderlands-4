# Changelog

## 1.0.0 - 2026-11-02

- First release: a LOGS & CONFLICTS entry in the pause menu and the main menu.
- The SDK's log, your user name hidden in folder paths, with COPY and OPEN FOLDER.
- The conflicts between your mods, with what to do for each: mods that did not load, mods installed twice, game files
  replaced by several mod packages, console commands and settings files used by two mods, and keys used by several
  mods, with the game's key names.
- COPY copies the conflicts in English, with the SDK's key names, for a mod's author.
- Texts in English, French and Simplified Chinese, following the game's language.
- Keyboard, mouse and gamepad.
- Under the Mozilla Public License 2.0, unlike the rest of its GitHub repository.
