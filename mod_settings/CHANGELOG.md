# Changelog

## 1.0.0 - 2026-10-26

- First release, ALPHA: a MODS entry in the pause menu and the main menu, one page for every SDK mod found, built
  with the game's own Options pieces.
- Switches, sliders, arrow choices, lists, keys and buttons, saved by the SDK.
- Texts in English, French and Simplified Chinese, following the game's language.
- Keyboard, mouse and gamepad.
