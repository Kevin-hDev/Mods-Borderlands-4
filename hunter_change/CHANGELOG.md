# Changelog

## 1.0.0 - 2026-09-29

- Initial release.
- APPEARANCE: wear another hunter's look in a game, back each time the game loads.
- HUNTER: become another hunter in a game, with the same level, backpack and story.
- Each hunter keeps their own skill tree in each game.
- Change from inside a game, through the main menu, or at once at the main menu.
- A backup copy of the save before each change.
- A settings window in English and French.
