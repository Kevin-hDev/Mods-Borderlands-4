# Jetpack Ascend

Jetpack Ascend を使うと、グライドするだけでなく、グライドパック（ゲームのジェットパック）で実際に上昇できます。上を向くと上昇し、正面や下を向くといつもどおりグライドします。強すぎることはなく、移動を少し快適にするためのMODです。

![グライドパックで空中を上昇するヴォルト・ハンター。画面下部にゲージが表示されている](images/jetpackascend/climbing.jpg){: width="1600" height="1296"}

## できること

- **上を向くと上昇**。グライド中に地平線より上を狙うと、グライドパックで上へ進みます。
- **それ以外はいつもどおりグライド**。正面や下を向いているときは、ゲーム本来のグライドと同じです。
- **使い切ることもあります**。グライドパックのゲージはそのまま残ります。上昇もグライドと同じようにゲージを消費し、MODは消費の速さを変えません。
- **マルチプレイ**。マルチプレイでも動作し、MODが必要なのはホストだけです。

## 設定

MODのオプションには2つの設定があります。

- **Ascend Speed**：上昇の速さ。200〜3,000（初期値は900。100で秒速約1メートル）。
- **Look-Up Threshold (degrees)**：グライドではなく上昇するために、地平線よりどれだけ上を狙う必要があるか。0〜80度（初期値は15度）。

## インストール

Jetpack Ascend には Oak2 Mod Manager が必要です：[インストールガイド](https://bl-sdk.github.io/oak2-mod-db/)。

1. Oak2 Mod Manager をインストールします。
2. Nexus ページから Jetpack Ascend をダウンロードし、その `.sdkmod` ファイルをゲームの `sdk_mods` フォルダーに置きます（`...\Borderlands 4\sdk_mods`）。
3. ゲームを起動します。
4. コンソールキー（US配列のキーボードで Esc の下にあるキー）を2回押してコンソールを開き、`mods` と入力して Enter を押します。
5. JetpackAscend の横に表示されている番号を押します。
