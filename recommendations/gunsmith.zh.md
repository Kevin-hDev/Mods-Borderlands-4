# Gunsmith

Gunsmith 把武器改装带进你的物品栏。分解不需要的枪械，发现它们的部件，再按你的玩法改装兼容的武器。

![物品栏中的 Gunsmith 标签页，显示武器预览及其部件](images/gunsmith/menu-1.jpg){: width="1600" height="906" loading="lazy"}

## 功能

- **一次发现，随意复用**。分解一把枪会永久解锁其可回收的部件变体。无需管理重复的副本：你的发现会成为可反复使用的收藏。
- **确认前先看效果**。游戏自带的武器预览会显示这把枪。将鼠标悬停在部件上可将其高亮，点击即可选中，对比改装后的属性，然后应用更换。
- **找到关键部件**。已安装和可用的部件分开列出。可以搜索、按类别筛选，并按属性排序。
- **把不要的战利品变成部件**。分解选中的枪械，或所有标记为垃圾的武器。
- **让心爱的武器跟上你的等级**。在工作台将受支持的武器提升到你角色的等级。
- **Share Discoveries**（1.0.8 新增）。开启后，所有角色已解锁的部件会合并在一起，之后的新发现也会共享。

更换只能在同一武器系列内进行：分解一把雅各布斯左轮手枪可以为其他兼容的雅各布斯左轮手枪解锁部件，但狙击枪的枪管不能装到手枪上。

## 使用方法

打开**物品栏 > Gunsmith**（位于 ECHO日志 标签页旁边），或将鼠标悬停在武器卡片上并按 **G**。

- 左键：选择部件。
- 按住右键：旋转武器。
- 在预览上滚动滚轮：缩放。
- 在部件列表上滚动滚轮：滚动列表。
- **Reset Preview** 恢复初始视角；**Change Weapon** 选择另一把武器。

只能修改未装备的武器。请先将武器从四个武器栏位中卸下，放入背包。

## 安装

Gunsmith 以原生 C++ 运行，使用游戏自带的物品栏界面和武器预览。它不需要 Python SDK，不需要安装 Python，也不需要在菜单中启用：所需的加载器和运行库已包含在内。

1. 关闭《无主之地 4》。
2. 从 Gunsmith 的 Nexus 页面下载并解压。
3. 将解压出的 `OakGame` 文件夹复制到《无主之地 4》的安装文件夹中，并允许文件夹合并。
4. 启动游戏，载入你的角色，然后打开**物品栏 > Gunsmith**。

更新时，关闭游戏，将新版本复制到旧版本上即可。完整说明（包括如何卸载）见 Nexus 页面。

## 开始前须知

- 请备份存档。分解会消耗武器，卸载不会归还武器，也不会撤销已保存的武器修改。
- 仅支持兼容的部件；不支持在不同类型的武器之间混用部件。
- 必需模块和传奇模块可能需要替换，而不能直接移除。
- 首次使用缩略图时可能出现短暂卡顿。
- 多人游戏、手柄、超宽屏和游戏的其他版本尚未经过验证。
- 其他修改物品栏界面的模组可能会冲突。

完整列表见 Nexus 页面。
